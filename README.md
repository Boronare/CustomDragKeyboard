# Custom Drag Keyboard

키 하나에 **9개 방향**(탭 + 8방향 드래그)의 입력을 담아, 적은 수의 큰 키로 모든 문자를 입력하는 안드로이드 키보드입니다.
자판의 크기와 방향별 동작을 모두 직접 설계할 수 있습니다.

2018년 중앙대학교 소프트웨어학부 팀135가 만든 프로젝트(Gabor Simon의 CompassKeyboard 기반)를
같은 기획으로 Kotlin과 Jetpack Compose를 써서 새로 만들었습니다. 원래 코드는 git 히스토리에 남아 있습니다.

## 기능

- **9방향 드래그 입력**: 키를 누르면 가운데 글자, 누른 채 밀면 그 방향의 글자가 입력됩니다. 드래그하는 동안 입력될 글자를 키 위에 미리 보여줍니다.
- **십자 + 각도 하이브리드 판정**: 짧게 그으면 상하좌우만 나오고, 감도 거리의 일정 배수(기본 1.8배) 이상 그어야 대각선이 됩니다. 그 거리부터는 45°씩 8방향으로 나눕니다. 짧은 드래그가 대각선으로 새는 일을 줄이며, 배수는 설정에서 바꿀 수 있습니다.
- **숫자 키패드**: 숫자·전화번호·날짜 입력칸에서는 자동으로 3×4 키패드(+ ⌫·⏎ 열)가 뜹니다. 아래 기호 키를 밀면 `+ / : *`, 전화번호에서는 `+ - ( ) , ;`가 나옵니다.
- **비밀번호 입력칸**: 한글을 조합하지 않고 두벌식 자판에서 같은 자리의 영문으로 바꿔 입력합니다(한 → `gks`, 닭 → `ekfr`). 추천과 학습도 꺼집니다.
- **상황에 맞는 엔터**: 검색창에서는 🔍, 메신저에서는 ➤처럼 입력창이 원하는 동작으로 표시와 동작이 함께 바뀝니다. 여러 줄 입력창에서는 줄바꿈입니다.
- **단어 추천**: 키보드 위 추천 줄에 후보 3개(가장 좋은 후보가 가운데)를 보여주고, 누르면 단어를 바꾸고 한 칸 띄웁니다. 아래 "단어 추천" 절 참고.
- **자판 편집기**: 가로 1–10칸, 세로 1–6줄. 방향마다 문자 입력, 특수 키(백스페이스·엔터·탭·커서), Android 키코드, 이전·다음 자판, 다른 입력기로 전환 중 하나를 지정하고, 키 위에 표시할 값을 따로 정할 수 있습니다. 크기를 바꿔도 기존 키는 유지됩니다.
- **여러 자판**: 순서 변경, 복제, 삭제. 키보드에서 `⌨▸` / `◂⌨` 동작으로 목록 순서대로 전환합니다.
- **내보내기/불러오기**: 자판을 JSON 파일로 공유합니다. 시스템 파일 선택기를 쓰므로 저장소 권한이 필요 없습니다.
- **한글 조합**: 두벌식 오토마타가 자모를 음절로 조합합니다. 겹받침, 이중모음, 받침 넘기기(닭+ㅏ → 달가)를 처리하고, 백스페이스는 입력한 순서를 거꾸로 되돌립니다(닭 → 달 → 다 → ㄷ).
- **좌우 여백과 여백 버튼**: 기본 5mm 좌우 여백이 있어 가장자리 키도 바깥쪽으로 드래그할 수 있습니다. 키에서 시작한 드래그는 여백까지 밀어도 그 키의 입력이고, 자판마다 왼쪽·오른쪽 여백에 원터치 동작을 하나씩 지정할 수 있습니다.
- **설정**: 진동(없음/약하게/강하게), 가로·세로 드래그 감도(mm), 키 높이(mm), 세로·가로 모드별 좌우·하단 여백(mm).
- 길게 누르면 반복 입력(백스페이스 등), 멀티터치, 다크 모드, 검색창 등에서 엔터를 누르면 그 입력창의 동작(검색·보내기 등)을 실행합니다.

기본 자판은 두 개입니다.

| 자판 | 설명 |
| --- | --- |
| 기본 (한/영) | 원작의 3×5 기본 자판. 한글·영문 대소문자·숫자·기호가 한 장에 모두 들어 있습니다. |
| English | QWERTY를 3×3 묶음으로 옮긴 영문 자판. 원래 QWERTY에서 글자가 있던 쪽으로 드래그합니다. |

## 단어 추천

원작은 키를 누를 때마다 SQLite에 `LIKE` 쿼리를 보냈습니다. 지금은 상용 키보드들과 같은 구조로 바꿨습니다.

- **메모리 색인**: 빈도 사전을 처음 쓸 때 백그라운드에서 읽어, 정렬된 배열에서 이진 탐색으로 접두어 범위를 찾습니다. 자음 하나처럼 범위가 가장 넓은 경우도 PC 기준 1ms 안팎입니다.
- **자모 단위 매칭**: 한글은 입력 순서대로 자모로 풀어서 비교합니다. "한"을 치는 중에도 받침이 넘어가는 "하나"를 찾고, "고"에서 "과자"를 찾습니다. 같은 글자 안에서 이어지는 후보(삼 → 삼성)를 받침이 넘어가는 후보(삼 → 사무실)보다 앞에 둡니다.
- **입력 학습**: 띄어쓰기·문장부호·엔터로 끝난 단어와 고른 추천 단어를 이 기기에만 저장해 순위에 반영합니다. 사전에 없는 활용형("했어요")이나 고유명사도 이렇게 배웁니다. 비밀번호 칸, 시크릿 모드(`IME_FLAG_NO_PERSONALIZED_LEARNING`)에서는 추천·학습하지 않고, 설정에서 끄거나 지울 수 있습니다.
- **사전 데이터**: [wordfreq](https://github.com/rspeer/wordfreq)(Robyn Speer, 데이터 CC BY-SA 4.0)로 만든 한국어 약 2.5만, 영어 약 5.9만 단어입니다. `tools/build_dictionaries.py`로 다시 만들 수 있습니다. 한국어 데이터는 형태소 단위라 조사·어미가 붙은 형태는 학습으로 채웁니다.

## 구조

```
core/   순수 Kotlin 모듈 (Android 의존성 없음, 단위 테스트 포함)
  Direction.kt        9방향 정의와 드래그 방향 판정
  KeyAction.kt        방향별 동작 (문자, 특수 키, 키코드, 자판 전환, 입력기 전환)
  KeyboardLayout.kt   자판 모델 (행×열 키, 키마다 9방향)
  LayoutCodec.kt      JSON 내보내기/불러오기 형식
  Composer.kt         한글 조합 오토마타
  KeyboardEngine.kt   키 동작 → 입력기 명령 변환
  Jamo.kt             단어 검색용 자모 정규화
  Suggestions.kt      빈도 사전, 입력 학습, 추천 순위
  DefaultLayouts.kt   기본 자판
app/    Android 앱
  ime/                InputMethodService와 자판을 그리는 Canvas 뷰
  data/               자판(JSON), 설정(SharedPreferences), 사전·학습 단어 저장소
  src/main/assets/dict/  추천 사전 (tools/build_dictionaries.py로 생성)
  ui/                 Compose 설정 앱 (시작하기, 자판 목록, 자판 편집기, 환경설정)
```

## 빌드

JDK 17과 Android SDK(API 35)가 필요합니다.

```sh
./gradlew :core:test          # 방향 판정, 한글 조합, 자판 형식 테스트
./gradlew :app:assembleDebug  # app/build/outputs/apk/debug/
```

GitHub Actions가 푸시할 때마다 테스트를 돌리고 디버그 APK를 artifact로 올립니다.

설치한 뒤 앱을 열어 **시작하기** 카드에서 키보드를 활성화하고 선택하면 됩니다.
